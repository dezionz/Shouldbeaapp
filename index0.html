STEP 01 — DEPLOY AS A WEB APP (FREE, 5 MINUTES)
Host on Vercel or Netlify
1. Go to vercel.com or netlify.com and create a free account. 2. Drag and drop your downloaded HTML file onto their dashboard — it deploys instantly. 3. You get a live URL like yourapp.vercel.app within seconds. 4. To use a custom domain (e.g. yourapp.com), connect it in the dashboard. Domains cost ~$10–15/yr on Namecheap or Google Domains. Cost: FREE for hosting · ~$10/yr for domain (optional)
vercel.com
netlify.com
namecheap.com
STEP 02 — ADD A BACKEND (IF YOUR APP NEEDS DATA/AUTH)
Set Up Supabase (Free Tier)
If your app needs user accounts, a database, or saved data: 1. Go to supabase.com and create a free project. 2. Get your project URL and anon key from Settings → API. 3. Add the Supabase JS client to your HTML: <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js"></script> 4. Replace placeholder config in the code with your Supabase credentials. Cost: FREE up to 500MB database · 50,000 monthly active users
supabase.com
Free tier available
STEP 03 — TURN IT INTO A MOBILE APP
Wrap with Capacitor (iOS + Android)
Convert your web app to a native iOS/Android app using Capacitor: 1. Install Node.js from nodejs.org 2. Run in terminal: npm install -g @capacitor/cli npx cap init YourAppName com.yourname.yourapp npx cap add ios npx cap add android 3. Copy your HTML file into the /public folder 4. Run: npx cap sync For iOS: Open in Xcode (Mac required), set your Apple Developer account ($99/yr), archive and submit to App Store. For Android: Open in Android Studio (free), generate signed APK, upload to Google Play Console ($25 one-time fee). Cost: Apple Developer = $99/yr · Google Play = $25 one-time
capacitorjs.com
developer.apple.com
play.google.com/console
nodejs.org
STEP 04 — ADD PAYMENTS (IF MONETIZING)
Stripe for Web · RevenueCat for Mobile
For web payments: Use stripe.com — create a payment link in minutes, no code required for basic checkout. For in-app purchases (iOS/Android): Use revenuecat.com — handles App Store and Google Play subscriptions with a simple SDK. Cost: Stripe = 2.9% + $0.30 per transaction · RevenueCat = Free up to $2,500 MRR
stripe.com
revenuecat.com
STEP 05 — ADD AN AI API KEY (IF YOUR APP USES AI)
Anthropic / OpenAI API Setup
If your generated app uses AI features: 1. Go to console.anthropic.com or platform.openai.com 2. Create an account and generate an API key. 3. IMPORTANT: Never put your API key in frontend code. Instead, use a free Vercel serverless function as a proxy: — Create /api/chat.js in your project — Store your key as an environment variable in Vercel dashboard — Your frontend calls /api/chat instead of the AI directly Cost: Pay-as-you-go. Claude Sonnet ~$3/million input tokens · GPT-4o ~$5/million tokens
